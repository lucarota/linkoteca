# Linkami

This is a free reimplementation of linkstore.app built with Python and React.

## Backend

To run the backend:

1. `cd backend`
2. `python -m venv venv`
3. `source venv/bin/activate`
4. `pip install -r requirements.txt`
5. `uvicorn main:app --reload --port 8000`

## Frontend

To run the frontend:

1. `cd frontend`
2. `npm install`
3. `npm run dev`
